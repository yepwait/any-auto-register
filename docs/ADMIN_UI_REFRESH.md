## 设计原则

- 正常态先显示额度、库存、任务和日常操作，不以常驻说明书占据首屏。
- 技术协议、统计口径和低频参数逐层展开；异常和费用确认不能为了简洁而隐藏。
- 使用现有深浅主题色、Ant Design 控件和按需加载，不引入新 UI 库或动画负担。
- 本轮不更改后端业务参数和 API 合约；折叠不等于删除或恢复默认值。

## 保真和安全验证

- Web 池 Form 使用 `preserve`、折叠项 `forceRender`、保存 `getFieldsValue(true)`，只合并白名单字段；打开页面只 GET 本地配置/状态。
- Web 池、补库配置原值从服务端写入 Form store，不用在首次挂载时以默认值覆盖。
- Web 池保存启用和手动补号都需费用确认；取消时不发 PUT/POST 执行动作。
- 被折叠字段校验失败会展开对应区域，不静默忽略；更换服务地址时不能悄悄复用旧管理员密钥。
- 额度未知仍禁止数值额度模式的手动补号，不将未知记作 0；可用账号模式只在相应数量可确定时允许。
- 巡检密钥留空不会提交覆盖原密钥；所有高级恢复/上传字段仍参与保存。
- 接码补库的每轮/每日 UTC/失败保护/账号冷却/恢复流程原样保存，开启与执行仍保留可能产生邮箱、接码费用的确认。
- 任务分页、状态摘要、日志中的停止/跳过能力，以及页面隐藏时停止轮询的逻辑保留。
